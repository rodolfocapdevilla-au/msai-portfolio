Jargon Glossary

Network engineering has a lot of short words. Here is what the ones on my résumé mean.

BGP
The system the internet uses so that different networks can tell each other how to reach them.
OSPF / IS-IS
Two ways for the routers inside one network to share maps and pick the best path for data.
MPLS
A way to send data along pre-set paths using short labels, so it travels faster and more predictably.
VPN
A private, protected connection across a public network, like a locked tunnel through the internet.
EVPN / VXLAN
Tools that let a large data center network act like one big flexible network.
QoS (Quality of Service)
Rules that give important traffic, such as video calls, priority over less urgent traffic.
SLA (Service Level Agreement)
A promise to a customer about how reliable and fast a service will be.
CPE (Customer Premises Equipment)
The network equipment installed at a customer's own site.
HLD / LLD (High-Level / Low-Level Design)
Two design documents: the big-picture plan, and the detailed settings for building it.
MOP (Method of Procedure)
A step-by-step checklist for making a change to a network safely.
Ansible
A tool that applies the same setup to many devices automatically, instead of by hand.
Wireshark
A tool that lets you see the data moving through a network, to find out what is going wrong.
